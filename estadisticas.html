Actualizar datos

Después de cada sesión: abre EA y pulsa el marcador. EA solo guarda los últimos 5 partidos de cada tipo, así que no lo dejes para otro día.

Conecta GitHub (solo la primera vez, y solo en el ordenador de quien vaya a actualizar). Así la web podrá publicar sola los datos nuevos.

  1. Abre crear clave en GitHub ↗ (con la cuenta dueña del repositorio).
  2. Ponle un nombre (por ejemplo Web Mysting) y una caducidad.
  3. En Repository access elige Only select repositories → honor-et-dignitas.
  4. En Permissions → Repository permissions, pon Contents en Read and write.
  5. Pulsa Generate token, cópiala y pégala aquí:

✅ Publicación automática activada en este navegador.

La clave se guarda solo en este navegador: ni en la web ni en el repositorio. No la compartas; puedes anularla cuando quieras desde GitHub.

Guarda el marcador. Arrastra este botón a la barra de marcadores del navegador (solo la primera vez; si ya tenías uno antiguo, sustitúyelo).

⚽ Exportar Mysting

No se pudo preparar el marcador: abre esta página desde la web publicada, no como archivo local.

Después de cada sesión: abre la API de EA y, con esa pestaña delante, pulsa ⚽ Exportar Mysting. Se abrirá esta página, recibirá los partidos y los publicará. Si el navegador bloquea la ventana emergente, permítela para proclubs.ea.com.
